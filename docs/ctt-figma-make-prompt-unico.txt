Crie a landing page do CTT (usectt.com.br): uma página única em português do Brasil, React + Tailwind + componentes shadcn/ui + gráficos com o Chart do shadcn sobre Recharts. Desktop primeiro e 100% responsiva (375px a 1440px), com tema claro e escuro.

PRODUTO
O CTT lê o histórico de corrida do Strava e monta uma edição dele. Não é dashboard, não é feed, não tem ranking. Posicionamento: "Seu Strava, editado." A página mostra o arquivo real do Felipe como exemplo (deixe claro que é um exemplo) e convida o visitante a conectar o próprio Strava.

DIREÇÃO VISUAL
Laboratório suíço de corrida: a tipografia de atitude da Bandit Running (números condensados enormes, tipografia como imagem) com a precisão da On Running (muito respiro, grid rígido, nada decorativo). Dados monocromáticos; uma única cor de sinal marca o que importa.

- Texto: Archivo largura normal, 16–18px, line-height 1.5, até 60 caracteres por linha.

- Números sempre tabulares. Formato brasileiro: 7.727 km, 42,5 km, 4:52/km. Títulos com text-wrap: balance.
- Escala: odômetro clamp(88px,19vw,260px); H1 clamp(44px,7.4vw,104px); H2 clamp(34px,4.6vw,64px); número de recorde clamp(40px,4.6vw,64px).
